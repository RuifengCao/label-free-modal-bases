# Phase 0c (exploratory): one network per mode

Written and hashed before any Phase 0c run, 6 November 2026. Exploratory: no hypothesis is tested.

## Why

Reading Shape Space Spectra again for Phase 0b (Algorithm 2 and Table 1 of arXiv 2408.10099v2) showed that it represents each eigenfunction by its own small MLP ("parameters per MLP"), whereas Neural Eigenfluid Bases and this work use one network with one output per mode. With one network per mode, Adam normalises each mode's gradient separately, so the eigenvalue-sized gradients of trace-type objectives may no longer starve mode 1. If so, the paper's claim must be limited to bases generated by one shared network, and the comparison should say so. Phase 0c checks this on G0 before the pre-registration is finalised.

## Runs

G0 (as Phase 0), 20,000 iterations, Adam 1e-3 cosine to 1e-5, monitoring every 1,000 iterations, same inputs ('hard_angle': 23 features) and exact clamp. Architecture "sep": 8 MLPs, each with 4 hidden layers of 24 (tanh) and 2 outputs (the x and y displacement of one mode); about 19,400 parameters in all, against 15,056 for the shared network of Phase 0. Initialisation: PRNGKey(seed) split into 8 keys, one per MLP.

Objectives (as in phase0.py and phase0b.py, applied to the assembled basis): O2 (trace), O3 (sequential Rayleigh quotients, fixed column order), O3s (the same after sorting the columns by their own Rayleigh quotients, as Chang et al. 2025), O4 (log-det).

Order of runs: seed 0 for O3, O3s, O2, O4; then seed 1 for O3s and O2; then seed 1 for O3 and O4 if time allows within the session. Evaluation: final Ritz errors of modes 1 to 8, sin^2 of the M-angle, E1 and E2 on the 10 evaluation cases, as Phase 0.

## What is looked at

Mode 1's error after 20,000 iterations, against the shared-network results of Phase 0 (O2: 12% to 20%; O3: 3.0% to 5.1%; O4: 0.07% to 0.09%). Expectation, stated before running (not tested): with one network per mode, O3 and O3s no longer leave mode 1 behind; O2 still does (its orthonormalisation couples each column to the later, stiffer ones); O4 learns all eight.

## Code

phase0/phase0c.py (imports phase0.py and phase0b.py unchanged). Checks before training: (C1) at the seed-0 initialisation the assembled basis has 8 columns and the JAX values of O2, O3 and O4 on it agree with phase0.objectives_np (relative 1e-9), and O3s agrees with O2 (its value is the trace; relative 1e-9); (C2) a smoke run of every objective for 20 iterations, in its own folder. Outputs: phase0/out0c/.
